NovaDesk Incident Report - INC-2026-10-06

Severity: P1 (critical)
Date: Tuesday, October 6, 2026 (monthly release day)
Start: 09:12 Cairo time
End: 12:42 Cairo time
Total downtime: 3 hours 30 minutes
Monthly uptime for October 2026: 99.53 percent

Summary
During the monthly release, a faulty database migration made the NovaDesk web application and API unavailable for all customers. The engineering team detected the problem at 09:12 through monitoring alerts and started working on it within 15 minutes.

Root cause
A database migration script locked the main tickets table. The script was not tested on a copy of production data before the release.

Resolution
The release was rolled back at 12:30 and services were fully restored at 12:42. Ticket data was not lost.

Affected customers
- Delta Logistics (Business plan, 12 agents, billed monthly): web app and live chat unavailable.
- Nile Bank (Enterprise plan, 25 agents, billed monthly): web app and API unavailable. Opened a P1 ticket at 09:20 and received the first response at 09:55.
- Cairo Bites (Starter plan, 3 agents, billed monthly): web app unavailable.
All other customers were also affected, but no further SLA claims were received.

Customer communication
A status page notice was published at 09:30. A final update was sent to all customers by email at 13:15.

Follow-up actions
1. Test every database migration on a copy of production data before release (owner: Engineering, Hana Mostafa).
2. Add automatic rollback to the release process (owner: Engineering).
3. Review service credit requests with Finance (owner: Khaled Samir).
